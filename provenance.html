Provenance

Where did this come from? Who made it? Can I verify?

Provenance is the habit of asking where did this come from, and can I check? An NFT without real onchain art is a claim without proof. A download without a checksum is a file you have to trust. A model without an open license or weights is a black box you're asked to have faith in. Provenance is the question that separates the real thing from the impression of it.

In crypto, provenance is a solved problem: the chain is a public, append-only record, and an onchain token's whole history is queryable. Who minted it, who held it, what does it render from — all of it verifiable, none of it a promise. That's a genuine advance over a URL. It's the first media format where the receipt is part of the artwork.

I want that same standard everywhere. This site is on a public repo with a visible commit history; the code is inspectable; the game runs from HTML you can read. An AI you can't inspect is just a vending machine for answers. Provenance is how you tell the difference between something that's real and something that's convincing.

THE QUESTION
  • NFT ....... mints from a function, not a URL
  • File ...... hash it, publish the hash
  • Model ...... open license, inspectable weights
  • This site . public repo, public commits
  • If I can't check where it came from, I don't trust it.
